# Vizuálny štýl portfólia

## Celkový dojem

Svetlý, čistý a moderný vizuál s dostatkom voľného priestoru. Mliečne biele
pozadie dopĺňajú vybrané béžové plochy, výrazná žltá pre hlavné akcenty a
jemná šalviová zelená len na drobné dekoratívne detaily. Nadpisy a texty
zostávajú grafitové, aby boli dobre čitateľné.

## Farebná paleta

| Použitie | Farba |
| --- | --- |
| Hlavné pozadie stránky | `#FAF9F6` |
| Pozadie vybraných sekcií | `#F0EDE6` |
| Hlavná akcentová farba a CTA | `#FFC43D` |
| Jemné dekoratívne detaily | `#A8B49A` |
| Nadpisy a hlavný text | `#343434` |
| Pozadie kariet | `#FFFFFF` |
| Sekundárny text | `#6B6A66` |

Udržiavať približné rozloženie 80 % svetlých neutrálnych plôch, 15 % žltých
akcentov a najviac 5 % šalviových detailov. Žltá má zostať sýta a výrazná;
nepoužívať pastelové odtiene. Zelenú vyhradiť pre malé značky, obrysy a
dekoratívne prvky, nie pre veľké plochy. Nepoužívať tyrkysovú ani tmavé
dominantné pozadia.

## Písmo a typografia

- Používať moderné bezpätkové písmo: Inter, Manrope alebo systémové sans-serif.
- Zachovať veľké, vzdušné nadpisy s tesným riadkovaním a ľahšou až strednou
  hrúbkou.
- Hlavný text a nadpisy používať v grafitovej farbe. Sekundárny text má byť
  dostatočne tmavý na pohodlné čítanie na svetlom pozadí.
- Žltú nepoužívať ako farbu textu na svetlých plochách; zvýraznenie riešiť
  žltým podčiarknutím, bodkou alebo dekoratívnym prvkom.

## Tlačidlá a odkazy

- Primárne tlačidlá majú výrazné žlté pozadie a grafitový text.
- Sekundárne odkazy používajú grafitový text a jemné žlté zvýraznenie pri
  interakcii.
- Všetky šípky pri tlačidlách a odkazoch majú jednotný rozmer a štýl.
- Ovládacie prvky majú pohodlnú výšku, viditeľný stav pri prejdení kurzorom
  a jasný indikátor klávesnicového fokusu.

## Karty, sekcie a ilustrácie

- Hlavné pozadie ponechať mliečne biele; vybrané sekcie môžu mať svetlú béžovú
  plochu.
- Projektové karty majú biele pozadie, jemné okraje a decentné tiene. Ich
  ilustrácie kombinujú bielu, béžovú, grafitovú a malé žlté akcenty.
- Hero ilustrácia má byť svetlá a bez tyrkysových či tmavomodrých plôch.
- Hero pozadie používa široké, mäkké žlté ambientné gradienty: výraznejšie
  vpravo hore a jemnejšie vľavo dole. Použiť viacero rozptýlených radiálnych
  vrstiev s rozostrením bez viditeľných kruhov, čiar, pásov alebo lúčov.
- Dekoratívna karta v hero sekcii je krémová, mierne natočená a má mäkký
  prirodzený tieň; písmeno zostáva grafitové so žltým detailom.
- Zachovať vzdušné rozostupy, zaoblenie kariet, jemné animácie a responzívne
  rozloženie.
- Pohybové efekty rešpektujú systémové nastavenie obmedzenia animácií.
